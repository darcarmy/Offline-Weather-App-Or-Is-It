# Offline-Weather-App-Or-Is-It
Offline Weather App but with a twist, written in shell script.

# How to Use
Make sure you satisfy the following prerequisites

* Git
* Bash / Posix Shell
* Linux / MacOS / WSL
* Terminal

### Clone Repository
```shell
git clone https://github.com/darcarmy/Offline-Weather-App-Or-Is-It.git
```

### Change directory
```shell
cd Offline-Weather-App-Or-Is-It
```

### Grant execution permissions
```shell
chmod +x script.sh
```

### Run the Script
```shell
./script.sh
```
